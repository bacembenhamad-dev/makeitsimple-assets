# What a token actually is (it is not a word)


**HOW IT WORKS**
## What a token actually is (it is not a word)
the model never sees your words

![slide 1](https://bacembenhamad-dev.github.io/makeitsimple-assets/posts/w1-s1-what-a-token-actually-is-it-is-not-a-word/slide-1.png)

- **Text is cut into sub-word chunks called tokens, shown with one sentence split live**
- **Rule of thumb** — 1 token is about 4 English characters, 100 tokens about 75 words
- **Why it matters** — context limits and invoices are counted in tokens, and code or non-English text uses more of them

![slide 2](https://bacembenhamad-dev.github.io/makeitsimple-assets/posts/w1-s1-what-a-token-actually-is-it-is-not-a-word/slide-2.png)
